Реализованы пять рекомендательных моделей с нуля: ItemKNN, iALS, EASE,
FM с временными метапризнаками и ALS с собственным знаковым целевым сигналом,
учитывающим давность оценки. Обучение, предсказания, top-10 и метрики реализованы
на NumPy/SciPy. Готовые рекомендательные алгоритмы не используются.

## Запуск

Python 3.9–3.12. Из корня репозитория:

```bash
cd Homework_1
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/run_notebook.py
```

## Данные и протокол

- Исходный CSV: 1 584 082 взаимодействия, 840 372 пользователя, 456 992 товара.
- Очистка: первая валидная оценка каждой пары user–item; 1 516 551 уникальная пара до отбора.
- Отбор по train: 7 000 наиболее часто оценённых товаров; минимум два разных товара
  на пользователя. После удаления пустых в train товаров: **112 972 взаимодействия,
  32 738 пользователей и 6 838 товаров**.
- Train: до 01.01.2015 UTC, 103 287 событий; validation: 2015 год, 5 806;
  test: с 01.01.2016 до конца выгрузки, 3 879.
- Отбор, кодирование и кандидаты фиксируются по train. Релевантность: оценка ≥ 4.
  Перед test модели заново обучаются на train+validation.
- Оценка на полном выбранном каталоге с исключением всех известных пользователю
  товаров. Новые пользователи и товары исключены; объём исключений показан в ноутбуке.
- Основная метрика: NDCG@10; дополнительная: Recall@10. Coverage@10 — диагностика.
  Подбор только на validation; параметры фиксируются до финальной оценки test.
- Seed 42; один поток BLAS; явные сетки параметров и SHA-256 исходных файлов сохранены.

FM использует user/item ID, календарные признаки запроса, строго предыдущие
счётчики активности и наблюдаемый возраст товара. Снимок внешних названий,
исполнителей и категорий применяется только для EDA и показа рекомендаций:
временная доступность этих полей не подтверждена, покрытие метаданных неполное.

Кастомный таргет для наблюдаемой оценки:

$$
p^*_{ui}=\frac{r_{ui}-3}{2}\,2^{-(T-t_{ui})/(86400\cdot730)}.
$$

Веса confidence совпадают с базовым iALS. Низкие оценки меняют знак предпочтения,
давность уменьшает модуль таргета. Неизвестные пары имеют нулевой таргет.
Есть контролируемые сравнения при одинаковых настройках ALS и абляция FM без метаданных.

## Результаты test

Общая когорта — 1 711 пользователей; validation — 2 583 пользователя.

| Модель | NDCG@10 | Recall@10 |
|---|---:|---:|
| EASE | 0.022632 | 0.035445 |
| ItemKNN | 0.021642 | 0.037150 |
| iALS | 0.020353 | 0.035755 |
| CustomALS | 0.019333 | 0.034781 |
| FM | 0.010304 | 0.013331 |

EASE лучший по основной метрике, ItemKNN — по Recall@10. Преимущество
кастомного сигнала и метапризнаков FM не подтверждено парными 95% интервалами.
Полные параметры, абляции и ограничения приведены в ноутбуке.
